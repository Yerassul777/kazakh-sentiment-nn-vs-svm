# kazakh-sentiment-svm
Kazakh review sentiment classification: SVM and Neural Network compared on the same 30k-feature matrix, with a bootstrap significance test

# Soft-margin SVM против нейросети на одинаковых признаках

Классификация тональности казахских отзывов. Обе модели получают одну и ту же матрицу признаков, одно и то же разбиение, одну и ту же балансировку классов. Отличается только способ разделения классов: у SVM гиперплоскость, у сети изогнутая граница.

## Метрики

Для класса, по тестовой выборке:

```
precision = TP / (TP + FP)
recall    = TP / (TP + FN)
F1        = 2 · precision · recall / (precision + recall)
macro-F1  = ( F1(negative) + F1(positive) ) / 2
```

**macro-F1** усредняет F1 классов с равным весом, независимо от их размера. Это основная метрика проекта: классы распределены 79 / 21, и модель, всегда отвечающая `positive`, даёт accuracy 0.79 при recall = 0 на негативном классе, то есть macro-F1 ≈ 0.44. Accuracy этот провал скрывает, macro-F1 показывает.

**ROC-AUC** — вероятность того, что случайный положительный отзыв получит больший score, чем случайный отрицательный. Не зависит от порога 0.5, оценивает качество ранжирования, а не конкретного решения.

**log-loss** — `−[y·log(p) + (1−y)·log(1−p)]`, усреднённая по выборке. Непрерывна по вероятности, в отличие от macro-F1, которая считается после жёсткого порога.

Ориентир: 0.44 у мажоритарного бейзлайна, 0.7652 достигнуто. Потолок ограничен шумом разметки, см. раздел «Анализ ошибок».

## Признаки

TF-IDF, два блока конкатенируются в одну разреженную матрицу:

```
tfidf(i, t) = tf(i, t) · log( N / df(i) )
```

где `tf` — вхождения терма в отзыв, `df` — число отзывов с этим термом, `N` — всего отзывов. Флаг `sublinear_tf=True` заменяет `tf` на `1 + log(tf)`.

| Блок | Параметры | Размер |
|---|---|---|
| word n-grams | `ngram_range=(1,2)`, `min_df=3` | 15 000 |
| character n-grams | `analyzer="char_wb"`, `ngram_range=(3,5)` | 15 000 |
| итого | без dimensionality reduction | 30 000 |

`min_df=3` — терм попадает в словарь, только если встретился минимум в трёх отзывах; отсекает опечатки-одиночки.

Character n-grams нужны по двум причинам, специфичным для этих данных. Казахский агглютинативный: `кітап`, `кітабы`, `кітапты` на уровне слов — три разных токена, но подстроку `кіта` делят. И опечаток много: лишняя буква портит несколько n-gram из десятков, тогда как на уровне слова создаёт новый неизвестный токен. Транслитерацию они не покрывают: у `keremet` и `керемет` нет общих символов.

Bigrams ловят отрицание: `жаман` = плохо, `жаман емес` = неплохо, и это самый сильный положительный вес в модели, +1.224.

## Model 1: soft-margin SVM

`LinearSVC(C=0.05, loss="squared_hinge", dual="auto", max_iter=6000, tol=1e-4)`

```
min  ½‖w‖²  +  C · Σ [ max(0, 1 − yᵢ(wᵀxᵢ + b)) ]²
```

Экспонента соответствует `squared_hinge`, дефолту sklearn. Классический hinge loss — `max(0, 1 − y·f(x))` без квадрата.

**Margin** — полоса между `f(x) = −1` и `f(x) = +1` вокруг гиперплоскости. Мягкой она называется потому, что точкам разрешено находиться внутри полосы и на чужой стороне: жалоба и похвала могут состоять почти из одних и тех же слов, hard margin решения не имеет. **C** — цена такого нарушения: малый C оставляет полосу широкой, большой сужает её вокруг обучающих точек.

**Decision score против distance.** `decision_function` возвращает `f(x) = wᵀx + b` — functional margin, не расстояние. Геометрическое расстояние: `d(x) = |wᵀx + b| / ‖w‖`. При `‖w‖ = 30.741` score 1.0 соответствует расстоянию 0.033.

### Подбор C

![Подбор C](figures/svm_c_sweep.png)

train macro-F1 растёт монотонно, validation достигает максимума на C = 0.05 и падает. Расхождение кривых и есть overfitting: gap растёт с 0.062 до 0.169. C выбран по максимуму validation, test при подборе не использовался.

## Model 2: neural network

`MLPClassifier(hidden_layer_sizes=(128, 32), activation="relu", solver="adam", alpha=1e-3, learning_rate_init=2e-4, batch_size=256)`

Вход — та же матрица 30 000, без сжатия. `ReLU(z) = max(0, z)`; без нелинейности стек слоёв сворачивается в одно линейное отображение. На выходе sigmoid `σ(z) = 1 / (1 + e^(−z))`, порог 0.5.

| Параметр | Значение | Смысл |
|---|---|---|
| `alpha` | 1e-3 | коэффициент L2-штрафа `α·Σw²` в функции потерь; единственный регуляризатор, dropout не используется |
| `learning_rate_init` | 2e-4 | размер шага, на который сдвигаются веса при одном обновлении; на дефолтном 1e-3 сеть достигала максимума validation за один проход |
| `batch_size` | 256 | число примеров, после которых обновляются веса |
| epoch | до 15 | один полный проход по всей обучающей выборке |
| early stopping | patience 4 | обучение останавливается после 4 эпох без роста validation macro-F1 |

Архитектура выбрана перебором трёх вариантов; разница между ними оказалась в пределах шума, поэтому взят наименьший из попавших в допуск 0.005.

### Обучение

![Кривые обучения](figures/nn_training.png)

train log-loss падает монотонно — это величина, которую минимизирует оптимизатор. validation log-loss достигает минимума на epoch 2 и разворачивается вверх: дальнейшие эпохи покупают запоминание train, а не обобщение. Модель для теста берётся с лучшей эпохи по validation macro-F1, поздние отбрасываются.

Расхождение метрик: минимум validation log-loss на epoch 2, максимум validation macro-F1 на epoch 1. Log-loss непрерывен по вероятности, macro-F1 меняется только когда отзыв пересекает порог 0.5, поэтому эпоха-победитель по этим двум критериям может не совпадать.

## Результаты

Тестовая выборка 17 516 отзывов, использована один раз.

![Результаты и bootstrap](figures/results.png)

| | macro-F1 | accuracy | ROC-AUC | параметров | время |
|---|---|---|---|---|---|
| soft-margin SVM | 0.7579 | 0.8177 | 0.8704 | 30 000 | 11 с |
| neural network | 0.7652 | 0.8258 | 0.8789 | 3 844 289 | ~3 мин |

Разница 0.0073 в пользу сети. Величина достаточно мала, чтобы её проверять, а не констатировать: тестовая выборка пересобиралась с возвращением 2 000 раз, обе метрики пересчитывались заново. **95% bootstrap CI = [0.0033, 0.0112]**, ноль не входит — преимущество устойчиво к пересэмплированию.

Что интервал не доказывает: превосходства в понимании языка. ROC-AUC у моделей 0.8704 против 0.8789, ранжируют они почти одинаково; разница берётся из положения порога 0.5.

## Анализ ошибок

| | значение |
|---|---|
| обе модели ошиблись | 2 679 отзывов (15.3%) |
| модели разошлись | 887 отзывов (5.1%) |

Общих ошибок втрое больше, чем расхождений — основная часть остаточной ошибки принадлежит данным, а не моделям. Среди общих ошибок есть отзывы с явно положительным текстом и оценкой в одну звезду; авторы датасета фиксируют то же самое.

**Accuracy по источникам:**

| источник | SVM | neural network |
|---|---|---|
| маркетплейсы | 0.930 | 0.926 |
| карты | 0.876 | 0.880 |
| приложения | 0.791 | 0.802 |
| книжный | 0.776 | 0.788 |

Разброс между источниками 15 пунктов против 0.7 пункта между моделями. Приложения дают 76% теста, поэтому общий балл почти совпадает с их баллом.

**Интерпретируемость.** У каждого признака ровно один вес, decision score — их сумма, поэтому модель можно спросить о причине решения. Сильнейшие негативные веса: `сапасыз` (−0.873), `ақылы` (−0.831), `пайдасы жоқ` (−0.814), `нашар` (−0.802). Позитивные: `жаман емес` (+1.224), `нашар емес` (+0.906), `ыңғайлы` (+0.832). У сети такого соответствия «признак → вес» нет.

Побочный эффект, который это вскрывает: в топе весов присутствуют `1жұлдыз`, `бір жұлдыз`, `4жұлдыз` — авторы дублируют свой rating словами внутри текста. Это не leakage из колонки меток, такие слова действительно есть в тексте, но задачу они упрощают.

## Вывод

Сеть выигрывает 0.0073 macro-F1, и bootstrap подтверждает, что выигрыш не случаен. Однако отрыв мал, обе модели упорядочивают отзывы почти одинаково, и платит сеть за него в 128 раз большим числом параметров, шестнадцатикратным временем обучения и полной потерей интерпретируемости.

Обе модели ошибаются на одних и тех же 15% отзывов и расходятся лишь на 5% — потолок задачи задаётся шумом разметки, а не выбором классификатора. Разброс по источникам данных (15 пунктов) на порядок превышает разброс между моделями (0.7 пункта).

По совокупности этих факторов для данной задачи практичнее soft-margin SVM: он достигает 99% качества сети, обучается за 11 секунд вместо трёх минут и способен назвать конкретные казахские слова, определившие решение. Проигрыш в macro-F1 существует, но не критичен, а выигрыш в скорости и прозрачности кратный.

## Ограничения

- Проверена одна схема labelling из трёх возможных; поведение при 3 звёздах как `positive` или при их исключении не измерялось
- Слова с названием rating внутри текста упрощают задачу
- Вывод справедлив для этих двух конфигураций, а не для двух семейств моделей вообще
- Oversampling дублирует строки, не добавляя информации
- Шум разметки виден, но не измерен количественно
- Character n-grams не связывают латиницу и кириллицу
- 76% теста приходится на один источник
- Использован один датасет
